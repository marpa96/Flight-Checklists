# Before Takeoff


**Owner:** Pablo Martinez
**Applies to:** C172S, VFR, IFR
**Revision:** 1.0
**Last updated:** 2026-11-15
**Source of truth:** [C172R POH § 4, p. 4-15](https://kerrville.cap.gov/media/cms/Cessna_172R_POH_712F3D6CCB3C7.pdf)

---
- [ ] Parking Brake -- SET
- [ ] Passenger Seat Backs -- MOST UPRIGHT POSITION
- [ ] Seats and Seat Belts -- CHECK SECURE
- [ ] Cabin Doors -- CLOSED and LOCKED
- [ ] Flight Controls -- FREE and CORRECT
- [ ] Flight Instruments -- CHECK and SET
- [ ] Fuel Quantity -- CHECK
- [ ] Mixture -- RICH
- [ ] Fuel Selector Valve -- RECHECK BOTH
- [ ] Throttle -- 1800 RPM
  - [ ] Magnetos -- CHECK (max 150 RPM drop each; max 50 RPM difference)
  - [ ] Vacuum Gage -- CHECK
  - [ ] Engine Instruments and Ammeter -- CHECK
- [ ] Annunciator Panel -- NONE ILLUMINATED
- [ ] Throttle -- CHECK IDLE
- [ ] Throttle -- 1000 RPM or LESS
- [ ] Throttle Friction Lock -- ADJUST
- [ ] Strobe Lights -- AS DESIRED
- [ ] Radios and Avionics -- SET
- [ ] NAV/GPS Switch (if installed) -- SET
- [ ] Autopilot (if installed) -- OFF
- [ ] Elevator Trim -- SET for takeoff
- [ ] Wing Flaps -- SET for takeoff (0° to 10°)
- [ ] Brakes -- RELEASE
