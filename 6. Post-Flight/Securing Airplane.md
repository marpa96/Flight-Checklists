# Securing Airplane

**Owner:** Pablo Martinez
**Applies to:** C172S, VFR, IFR
**Revision:** 1.0
**Last updated:** 2026-11-15
**Source of truth:** [C172S POH § 4](https://www.befa.org/wp-content/uploads/2019/12/POH-Cessna-172S.pdf)

---
- [ ] Parking Brake -- SET
- [ ] Electrical Equipment, Autopilot (if installed) -- OFF
- [ ] Avionics Master Switch -- OFF
- [ ] Mixture -- IDLE CUTOFF (pulled full out)
- [ ] Ignition Switch -- OFF
- [ ] Master Switch -- OFF
- [ ] Control Lock -- INSTALL
- [ ] Fuel Selector Valve -- LEFT or RIGHT (prevents cross-feeding)
- [ ] Keys -- Set on Glareshield/ In Binder
