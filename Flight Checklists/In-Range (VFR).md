# In-Range Checklist

>**Approx Completion Time**: 10 Mins
>
> **Purpose:** Lighten the load on final landing and approach checklists
>
> **Important:** Standard In-Range is able to obtain destination ATIS[^1]

[^1]:The range of ATIS capture may vary from 20 NM to 60 NM.

## Main Checklist

### Configuration

- [ ] **Autopilot** — Set if possible

#### Fuel Tanks

| Fuel Tank Type | Then take this action... | Condition |
|---|---|:---:|
| Selectable | Select fullest and set tank-switch timer | Monitor Timer|
| Both can be selected | Set/Ensure set to "Both" | Cross-Check |
| Unable to set "Both" | Select Fullest and calculate endurance. Advise other pilot of endurance | Warning |

- [ ] **Nav Lights** — Set
- [ ] **Strobes** — Set
- [ ] **Exterior Lights** — Set
- [ ] **Pressurization** — Set

### Communication

- [ ] **Destination Tower/ CTAF** — Set on standby freq
- [ ] **Destination ATIS** — Set on backup radio
- [ ] **Parachuting/ TFR/ Special Activities** — Check active times on Sectional
  
### Weather

> [!TIP]
> If only a couple of minutes from 56 on the hour, wait until the latest ATIS comes out if possible

- [ ] **Destination ATIS** - Obtain
  - [ ] **Ceilings** — Meet VFR Requirements
  - [ ] **Temp-Dewpoint Spread** — Calculate
  - [ ] **Information Designation** — Obtain
- [ ] **Destination Runway** — Determine/Confirm
- [ ] **Altimeter** — Set as per ATIS

> [!CAUTION]
> If weather are not within minimums personal or otherwise, consider diverting to alternate
