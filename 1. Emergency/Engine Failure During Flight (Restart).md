# Engine Failure During Flight (Restart)

> [!WARNING]
> **UNVERIFIED.** Condensed from the Cessna 172S POH, Section 3, page 3-5. Check every item, and mark the POH's bold memory items, before use.

**Owner:** Pablo Martinez
**Applies to:** C172S, VFR, IFR
**Revision:** 0.1 (unverified)
**Last updated:** 2026-11-16
**Source of truth:** [C172S POH § 3, p. 3-5](https://www.befa.org/wp-content/uploads/2019/12/POH-Cessna-172S.pdf)

---
- [ ] Airspeed -- 68 KIAS
- [ ] Fuel Shutoff Valve -- ON (push full in)
- [ ] Fuel Selector Valve -- BOTH
- [ ] Auxiliary Fuel Pump Switch -- ON
- [ ] Mixture -- RICH (if not restarted)
- [ ] Ignition Switch -- BOTH (START if propeller stopped)

> [!NOTE]
> Windmilling vs. stopped propeller: see the note on page 3-5.

- [ ] Auxiliary Fuel Pump Switch -- OFF

> [!NOTE]
> If fuel flow drops to zero after this step, see the note on page 3-5.
