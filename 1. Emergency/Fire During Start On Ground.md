# Fire During Start On Ground

> [!WARNING]
> **UNVERIFIED.** Condensed from the Cessna 172S POH, Section 3, page 3-7. Check every item, and mark the POH's bold memory items, before use.

**Owner:** Pablo Martinez
**Applies to:** C172S, VFR, IFR
**Revision:** 0.1 (unverified)
**Last updated:** 2026-11-16
**Source of truth:** [C172S POH § 3, p. 3-7](https://www.befa.org/wp-content/uploads/2019/12/POH-Cessna-172S.pdf)

---
- [ ] Ignition Switch -- START; keep cranking

### If engine starts
- [ ] Power -- 1800 RPM for a few minutes
- [ ] Engine -- SHUT DOWN; inspect for damage

### If engine fails to start
- [ ] Throttle -- FULL OPEN
- [ ] Mixture -- IDLE CUTOFF
- [ ] Cranking -- CONTINUE
- [ ] Fuel Shutoff Valve -- OFF (pull full out)
- [ ] Auxiliary Fuel Pump Switch -- OFF
- [ ] Fire Extinguisher -- ACTIVATE
- [ ] Engine -- SECURE
  - [ ] Master Switch -- OFF
  - [ ] Ignition Switch -- OFF
- [ ] Parking Brake -- RELEASE
- [ ] Airplane -- EVACUATE
- [ ] Fire -- EXTINGUISH
- [ ] Fire Damage -- INSPECT; repair before next flight
