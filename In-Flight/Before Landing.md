# Before Landing

> **Approx. Completion Time:** 2 Minutes
> **Purpose:** Lighten the load on final landing and approach checklists

> [!IMPORTANT]
> Standard In-Range is able to obtain destination ATIS[^1]

**Owner:** Pablo Martinez
**Applies to:** ASEL VFR
**Revision:** 0.1  
**Last updated:** 2026-08-02

- [ ] Pilot and Passenger(s) **Seat** Backs - **MOST UPRIGHT POSITION**
- [ ] Seats and **Seatbelts** - **SECURE and LOCKED**
- [ ] **Fuel Selector Valve** - set **BOTH**
- [ ] **Mixture** - **RICH**
- [ ] Landing/ Taxi **Lights** - **ON**
- [ ] **Autopilot** - **OFF**
