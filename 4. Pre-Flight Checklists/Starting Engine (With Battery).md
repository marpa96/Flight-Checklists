- [ ] Throttle - OPEN 1/4 INCH
- [ ] Mixture - IDLE CUTOFF
- [ ] Propeller Area - CLEAR BOTH SIDES
- [ ] Master Switch - ON
- [ ] Flashing Beacon - ON

> [!NOTE]
> if engine is warm, omit priming procedure of steps 6,7 and 8 below

- [ ] Auxillary Fuel Pump Switch - ON
- [ ] Mixture - Set to FULL RICH (Full forward) until stable fuel flwo is indicated (usually 3 to 5 seconds), then set to IDLE CUTOFF (Full aft) position
- [ ] Auxillary Fuel Pumo Switch - OFF
- [ ] Inigition Switch - START (release when engine starts)
- [ ] Mixture - advance smoothly to rich when engine starts

> [!CAUTION]
> if engine floods (engine has been primed too much)
> - [ ] Auxillary Fuel Pump - OFF
> - [ ] Mixture - IDLE CUTOFF
> - [ ] Throttle - 1/2 to FULL OPEN
> - [ ] Ignition - START (Crank Engine)
> 
> Once the engine starts:
>  - [ ] Mixture - FULL RICH
>  - [ ] Throttle - FULL AFT 

- [ ] Oil Pressure - CHECK
- [ ] Navigation Lights - ON as required
- [ ] Avionics Master Switch - ON
- [ ] Radios - ON
- [ ] Flaps - RETRACT
