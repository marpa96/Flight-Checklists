### Electric System
- [ ] Alternator Ammeter - Ensure **NO DISCHARGE**

> [!WARNING]
> **If** ammeter shows **discharge** alternator failure is possible. Reduce electrical load. **LAND ASAP**

### Autopilot/ Navigation
- [ ] **Autopilot** (If Available) - **SET** to fly most recent clearance
#### Lateral

| Clearance Type |Fly ...|
|:---:|:---|
| Vectors| Direct from point of comms failure to fix or route assigned by vectors |
| No Assigned Route/ Fix |Route/fix ATC advised may be expected|
| No Expected route/fix |Filed clearance|

#### Vertical/ Altitude
Fly **highest of**:
- Assigned Altitude
- Altitude ATC Advised you to expect
- MEA/MOCA

### Radios
- [ ] ATC - Tune last known-good frequency
  - [ ] Ask for new frequency

> [!TIP]
> If another aircraft can hear you on the radio, try to use them as a relay to re-establish comms with ATC

- [ ] Alternate Radio - Set last known-good frequency to ACTIVE
  - [ ] Ask for new frequency
- [ ] Chart/ AIRAC/ GPS - Obtain freq. for center/approach
  - [ ] Set ACTIVE COM1/COM2
- [ ] **Flight Service** - **contact** over nearby NAVAID
- [ ] GUARD (121.5 MHz) - Attempt calling

### Handheld Radio

> [!TIP]
> Place the handheld radio close to the window for best reception

- [ ] **Handheld Radio - Attempt ALL previous steps**

### If Handheld not working

- [ ] **Transponder - SET 7600**
- [ ] Continue contact attempts on last known-good frequency
